# Groggle — Shopping List Mobile App

## Description

Groggle is an Android application for managing your shopping list with multi-currency support, automatic price conversion, and local data storage. The app allows you to:
- Add products with prices in your selected currency
- Automatically convert prices using up-to-date rates (via exchangerate.host)
- Store and display the total sum in the selected currency
- Easily choose currency and price display mode
- Save user preferences

## Key Features

- Modern and user-friendly UI
- Fast product adding and editing
- Support for RUB and all popular currencies
- Automatic currency rate updates
- Local data storage (Room)
- Instant application of settings
- Integration with exchangerate.host API (API key supported)
